Shopping sites Per-site buttons & posting options

Per-site switches for what the extension shows and posts on each site. All off by default.

Warning: Enabling "AP Non-Prod" for any website will automatically post a deal for every new page visit (e.g. search queries, categories, etc.) you browse on that website, unless you have visited that exact page within the cooldown period.
Repeat protection
One window for every way a deal goes out. Inside it, the same product is never posted twice: a convert you trigger yourself asks you first (post again or cancel); any posting path that cannot ask is skipped and reported. Counting starts from the last successful post of that product.

Chooses which Convert buttons show on real product pages for every store. Convert Only makes an affiliate link without posting. Convert Share converts, then asks your Affiliaters account to post that one deal to the destinations you connected there. At least one must stay on. The store’s Convert Button must also be on.
Non-product pages buttons
Chooses which floating buttons show on search, category, and home pages for every store. Convert Only makes an affiliate link without posting. Convert Share converts, then asks your Affiliaters account to post that one deal to the destinations you connected there. At least one must stay on. Requires Convert Button on for that store, and you must be logged in.
How autopost will work?
  1. Turn on Auto Post for any site above.
  2. Open a product page on that site. The deal is posted automatically — no clicks — using your saved Message format.
  3. It posts from the account you are logged in to (the one shown at the top). If you’re not logged in, it won’t post and shows an error instead.
  4. A small box appears bottom-right: Hunny on work… → Autopost completed. Press Stop there anytime to turn it off for that site.
  5. The same product won’t post again until Repeat protection above expires (default 1 hour). After that, visiting it can post again.
  6. It only runs on real product pages — never on search, category, or home pages.
Message format Customize the deal text

Tap a tag to insert it at your cursor. Leave blank for the default.

    How tags work
    • {{link}} is required — the affiliate link is placed here.
    • {{coupon}}/{{mrp}}/{{discount}}/{{off}} appear only when the site provides them; a line with only empty tags is removed (no “MRP: ” left behind).
    • {{finalprice}} = price after the coupon (Amazon only) — e.g. ₹649 with “5% coupon” → ₹617; with no coupon it shows the normal price.
    • Limit length: {{title[40]}} trims to 40 chars and adds “...”.
    • Fallback: {{mrp|N/A}} shows “N/A” when empty.
    • Multi-page tags: {{'Price: ', 'Starts from: ', price}} (or finalprice) shows "Price: [value]" on products and "Starts from: [value]" on lists. Use {{'@ ', price}} (2-parts) to show on product pages and hide completely on list pages.
    All variables
    • {{title}} — product/page title.
    • {{price}} — selling price (e.g. ₹27990).
    • {{mrp}} — list/struck price when higher than price.
    • {{link}} — product URL (converted to affiliate link).
    • {{discount}} — ₹ saved vs MRP (MRP − price).
    • {{off}} — % off vs MRP (e.g. 44%). Use in {{if off >= 20}}.
    • {{coupon}} — Amazon/Myntra coupon text when present.
    • {{coupon_amt}} — ₹ value of that coupon (from % or flat ₹).
    • {{finalprice}} — price after Amazon coupon math.
    • {{card_bank}} — Flipkart Best Value bank (e.g. HDFC). Empty on other sites for now.
    • {{card_type}} — Credit / Debit / Credit/Debit.
    • {{card_offer}} — full Best Value offer line from Flipkart.
    • {{card_off}} — best display: 10% or ₹2250.
    • {{card_off_pct}} — numeric % (e.g. 10) for display/compare.
    • {{card_off_amt}} — ₹ amount when known (e.g. ₹2250).
    • {{website}} — retailer id: amazon, flipkart, myntra, croma, shopsy.
    Math (price − coupon − card off)

    Safe calculator: field names, numbers, and + - * / ( ) only. Money results print as ₹. Missing coupon/card off count as 0; missing price → empty.

    • {{math price - coupon - card_off}} — pay after Amazon coupon + bank off (card_off uses ₹ amt, or price×% when only %).
    • {{math price - card_off}} — Flipkart: selling price minus Best Value off.
    • {{math finalprice - card_off_amt}} — after coupon, then subtract ₹ bank off.
    • Wrap with {{if card_off_pct >= 5}} so the line only shows for strong bank offers.
    Compose (custom text + values)

    Mix quoted text and field names. Empty fields become blank; if every field is empty the compose drops.

    • {{compose 'Apply ', card_bank, ' ', card_type, ' to get ', card_off}} → Apply HDFC Credit to get 10%
    • {{compose 'Price: ', price, ' (was ', mrp, ')'}}
    • {{compose title, ' — ', off, ' off'}}
    • {{compose 'Bank: ', card_bank, ' · ', card_offer}}
    If / else / endif

    Show a block only when a field exists, or when a number comparison passes. One {{else}} max; no nesting.

    • {{if price}}…{{endif}} — when selling price exists.
    • {{if mrp}}…{{else}}…{{endif}} — with optional else.
    • {{if off >= 20}} — MRP discount % at least 20.
    • {{if card_off_pct >= 5}} — Flipkart Best Value % at least 5.
    • {{if card_off_amt}} — when a ₹ bank off amount exists.
    • {{if website = 'amazon'}} — per-site block (also 'flipkart', or 'https://amazon.in' for *.amazon.in). Value must be in quotes.
    • {{if website = 'amazon'}}…{{else}}…{{endif}} — else = fallback for every other site.
    • Ops: > < >= <= = !=
