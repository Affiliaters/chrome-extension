MRP %: off = round((mrp − price) / mrp × 100).

Coupon: coupon is the text line; coupon_amt is the ₹ amount parsed from it (from % or flat ₹). Used in {{math}} as coupon. Flipkart uses the Coupons / “Save ₹X extra” row (same Apply ₹X coupon shape as Amazon).

Card offers: Flipkart Best value for you and Amazon mobile cardification cashback cards — non-EMI only. Same card_* keys on both sites. Warm/fetch runs only when nested {{if}} can reach those keys for the current site (website / price / mrp / off checked).

Basics

  • {{link}} is required — the converter places the affiliate URL here.
  • A line whose tags are all empty is dropped (no leftover MRP: ).
  • Truncate: {{title[40]}} trims to 40 chars and adds “...”.
  • Fallback: {{mrp|N/A}} shows “N/A” when empty.
  • Product vs listing prefixes: {{'Price: ', 'Starts from: ', price}} — product page vs list page wording.
  • Use {{'@ ', price}} (2-part) to show on product pages and hide on list pages.

Math

Compute a number from fields. Only + - * / ( ), numbers, and known numeric fields — no JavaScript.

{{math price - coupon - card_off}}
{{math price - card_off}}
{{math finalprice - card_off_amt}}
  • In math, coupon = ₹ coupon amount; card_off = ₹ bank off (card_off_amt, or price × card_off_pct / 100 when only %).
  • Money results format as ₹. Result ≤ 0 or missing price → empty (line can drop).
  • Missing optional subtractors (no coupon / no card) count as 0.
{{if card_off_pct >= 5}}
Pay {{math price - card_off}}
{{endif}}

Allowed fields: price, mrp, discount, off, finalprice, coupon, coupon_amt, card_off, card_off_pct, card_off_amt.

Compose

Mix quoted text and field names into one line:

{{compose 'Apply ', card_bank, ' ', card_type, ' to get ', card_off}}
→ Apply HDFC Credit to get 10%
   (or Apply Flipkart Axis Credit to get ₹4000)

More examples:

{{compose 'Price: ', price, ' (was ', mrp, ')'}}
{{compose title, ' — ', off, ' off'}}
{{compose 'Bank: ', card_bank, ' · ', card_offer}}
{{compose 'Save ', discount, ' (', off, ')'}}
Empty fields become blank (spaces collapse). If every field in the compose is empty, the whole compose is empty and the line can drop. Prefer wrapping with {{if card_off}} or putting compose inside a site block when you only want it sometimes.

Per-site (website)

{{website}} is the retailer id: amazon, flipkart, myntra, croma, shopsy.

Match by id or base URL (subdomains included). Quotes are required ('…' or "…"):

{{if website = 'amazon'}}
{{if website = "amazon"}}
{{if website = 'https://amazon.in'}}
{{if website = 'amazon.in'}}
{{if website != 'flipkart'}}

'https://amazon.in' / 'amazon.in' matches amazon.in, www.amazon.in, m.amazon.in, etc.

Rules: one {{else}} per {{if}}; nested {{if}} is supported. Close every block with {{endif}}. Bare {{if website = amazon}} (no quotes) is invalid — Save will show an error.
