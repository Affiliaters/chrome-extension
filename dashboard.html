How autopost will work?
  1. Turn on Auto Post for any site above.
  2. Open a product page on that site. The deal is posted automatically — no clicks — using your saved Message format.
  3. It posts from the account you are logged in to (the one shown at the top). If you’re not logged in, it won’t post and shows an error instead.
  4. A small box appears bottom-right: Hunny on work… → Autopost completed. Press Stop there anytime to turn it off for that site.
  5. The same product won’t post again until the cooldown above passes (default 1 hour). After that, visiting it can post again.
  6. It only runs on real product pages — never on search, category, or home pages.
Message format Customize the deal text

Tap a tag to insert it at your cursor. Leave blank for the default.

How tags work
  • {{link}} is required — the affiliate link is placed here.
  • {{coupon}}/{{mrp}}/{{discount}}/{{off}} appear only when the site provides them; a line with only empty tags is removed (no “MRP: ” left behind).
  • {{finalprice}} = price after the coupon (Amazon only) — e.g. ₹649 with “5% coupon” → ₹617; with no coupon it shows the normal price.
  • Limit length: {{title[40]}} trims to 40 chars and adds “...”.
  • Fallback: {{mrp|N/A}} shows “N/A” when empty.
